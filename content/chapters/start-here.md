## 本書使用方法

| 階段                 | 做法                                                                                                       |
| -------------------- | ---------------------------------------------------------------------------------------------------------- |
| 第一輪：建立地圖     | 先讀每章「一句話定位」與比較表，不急著背細節。目標是看到情境就能判斷題目在問架構、身分、安全、治理或合規。 |
| 第二輪：做情境判斷   | 完成章末小練習與兩份模擬題。每題都要說出「為什麼正確」以及「其他選項錯在哪個範圍」。                       |
| 第三輪：針對弱點補洞 | 用錯題標籤分類：名詞混淆、產品範圍、責任歸屬、最佳解、題幹否定詞。只重讀對應段落。                         |
| 最後一輪：壓縮記憶   | 使用速查表、口訣與辭典。考前不再開新教材，避免把已經整理好的腦袋重新倒進攪拌機。                           |
